Variables (змінні)

Змінну в Python найзручніше уявити як ярлик, що вказує на певне значення. Це позбавляє нас необхідності щоразу дублювати самі дані: ми просто “привʼязуємо” до них ім'я і далі використовуємо його у коді. Для створення такого зв’язку слугує знак =, що виконує роль команди присвоєння, а не рівності.

Цей ярлик можна багаторазово переміщувати на інші значення. При цьому діють чіткі правила: назва змінної не може мати пробілів і починатися з цифри. 

age = 22
name = "Олена"
height = 161.5

print(name)

age = 23  # зміна значення
print(age)

Python автоматично визначає, який тип даних зберігається у змінній. Текст завжди береться в лапки!

float дробове число 3.14, -0.5
str текст (рядок) "привіт", 'Python' 
score = 95       # int

print(type(score)) # перевірка типу

print() та input()

▶

print та input — це готові функції, вбудовані в Python. Функція — це наче кнопка з готовою дією: ми просто “натискаємо” на неї, а вона виконує свою роботу. Нам не треба знати, як вона працює всередині — головне знати, що вона робить і як її викликати.

Щоб викликати функцію, пишемо її назву, а після — круглі дужки (). Усе, що ми хочемо "передати" функції для роботи, пишеться всередині цих дужок. Це називається аргумент.

Дія Код
Вивести текст 
print("текст")
Вивести число 
print(5)
Вивести декілька значень 
print(name, age, "років")
Запитати текст 
name = input("Підказка: ")
Запитати ціле число 
age = int(input("Підказка: "))
Запитати дробове число 
weight = float(input("Підказка: "))

Функція print()

Виводить текст або значення змінної на екран. Аргумент — те, що пишемо в дужках (). Кілька значень через кому виводяться в одному рядку. 

print("Hello, world!")

name = "Olena"
print("Hello,", name)

print(5 + 3)  # можна виводити результат обчислень

Функція input()

Зупиняє програму і чекає, поки користувач введе текст. Всередині дужок пишемо текст – підказку для користувача, що він має ввести. Введене значення треба зберегти у змінну.

⚠️ Важливо: input() завжди повертає текст (str), навіть якщо ввести число! Щоб перетворити текст на число, треба використати int() або float(). 

age = input("Скільки тобі років? ")
print(type(age)) # <class 'str'>, навіть якщо ввели число

age = int(age) # перетворення на ціле число
print(age + 1) # тепер працюють мат. оператори

Поєднання тексту та формул (f-strings)

▶

f-рядок — це звичайний рядок з літерою f перед лапками. В такому рядку всередині фігурних дужок {} можна писати змінні, формули та функції, а Python сам обчислить та підставить результат. 

x = 3

print(str(x) + "^2 = " + str(x ** 2)) # спосіб 1
print(f"{x}^2 = {x ** 2}")            # спосіб 2

name = "Olena"
print(f"Hello, {name}!")

Швидке округлення чисел

У f-рядках є вбудований спосіб округлювати дробові числа — формат :.Nf (де N — кількість знаків після коми). 

pi = 3.14159265
print(f"{pi:.2f}") # 3.14
print(f"{pi:.0f}") # 3

price = 249.998
print(f"Ціна товару: {price:.1f} грн") # Ціна товару: 250.0 грн

print(f"10 / 3 = {10/3:.4f}") # 10 / 3 = 3.3333

Модуль math

▶

Підключення бібліотек (import)

Бібліотека — це готовий набір функцій, які написали інші розробники, щоб ми не винаходили велосипед. Щоб користуватись бібліотекою, її потрібно підключити один раз на початку файлу командою import.

Без import math Python не знатиме, що таке math.sqrt і видасть помилку. 

import math

print(math.sqrt(16)) # квадратний корінь (4.0)

Використання констант

Константа — це готове значення, яке вже “вшите” в бібліотеку. Наприклад, число π (пі) в бібліотеці math. 

import math

print(math.pi) # 3.141592653589793

radius = 5
length = 2 * math.pi * radius

print(f"Довжина кола: {length:.2f}")

math.ceil та math.floor

  • math.ceil(x) — завжди округлює вгору (наскільки б близько число не було до меншого цілого).
  • math.floor(x) — завжди округлює вниз.
  • round(x) — стандартна функція (не потребує import), округлює до найближчого цілого. 
import math

number = 4.1

print(math.ceil(number))  # 5 (вгору)
print(math.floor(number)) # 4 (вниз)
print(round(number))      # 4 (до найближчого)

Практичний приклад: скільки коробок потрібно, щоб упакувати 23 яблука по 5 в кожній коробці? 

import math

apples = 23
per_box = 5

boxes = math.ceil(apples / per_box)
print(f"Потрібно коробок: {boxes}") # 5, бо 4 не вистачить
