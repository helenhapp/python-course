Робота з файлами та обробка помилок

Мета цього уроку:

  • Навчитися зберігати дані програми у файлах так, щоб вони не зникали після закриття програми.
  • Навчитися обробляти помилки так, щоб програма не завершувалася аварійно при некоректних діях користувача.

Теорія 1: Читання файлів

▶

Читання даних з файлів

Коли під час роботи програми ти запитуєш в користувача якісь дані і зберігаєш їх у змінних (наприклад, створюєш список із назвами фільмів), ці дані насправді зберігаються лише до завершення роботи програми. Якщо ж ти хочеш, щоб дані не зникали, можна зберегти їх у файлі (наприклад, у тестовому файлі – з розширенням .txt). За допомогою коду можна відкривати текстові файли, зчитувати з них інформацію, змінювати або повністю переписувати їх вміст – і сьогодні ми дізнаємося як.

Створення текстових файлів в Thonny

Перш ніж програма зможе прочитати файл, цей файл має існувати. Створити його можна прямо в Thonny:

  1. Файл → Нове — відкриється новий порожній файл.
  2. Введи в нього потрібний текст (наприклад, список імен, по одному на рядок).
  3. Файл → Зберегти як, обери папку і збережи файл з розширенням .txt (наприклад, names.txt).

Важливо: текстовий файл повинен бути збережений в тій самій папці, що й файл з кодом (.py). Якщо вони в різних папках, Python не знайде файл за назвою. Перевірити, які файли є в поточній папці, можна через Вигляд → Файли в Thonny. Якщо вручну редагуєш вміст файлу, щоб зберегти зміни, треба натиснути Ctrl + S.

Відкриття файлу та оператор with

Щоб прочитати файл, спочатку потрібно його відкрити функцією open(). Найзручніший спосіб зробити це — за допомогою оператора with, який автоматично закриває файл після завершення роботи з ним: 

with open("names.txt", "r") as file:
    content = file.read()

print(content)
  • "names.txt" – назва файлу, який ми намагаємося відкрити.
  • "r" означає режим читання (read) — файл відкривається лише для читання, змінювати його не можна.
  • Змінна file – об'єкт файлу, через який ми отримуємо доступ до його вмісту.

Якщо ти спробуєш відкрити для читання файл, якого немає в папці з програмою, Python зупинить роботу і видасть помилку: FileNotFoundError: [Errno 2] No such file or directory: 'clues.txt' . Як правильно обробляти такі ситуації, щоб програма не ламалася, ми розглянемо в третій частині уроку.

Методи read() та readlines()

Є кілька способів прочитати вміст файлу:

  • file.read() – повертає увесь вміст файлу суцільним текстом. 
    with open("names.txt", "r") as file:
    content = file.read()

print(repr(content))
  • file.readlines() – повертає список, у якому кожен елемент є одним рядком файлу. 
    with open("names.txt", "r") as file:
    names = file.readlines()

print(names)
print("-" * 15)

for name in names:
    print(name)

Метод strip()

Кожен рядок, отриманий через readlines(), зазвичай закінчується символом переходу на новий рядок \n. Метод .strip() прибирає зайві пробіли та символи \n з початку і кінця рядка: 

with open("names.txt", "r") as f:
    names = f.readlines()

for n in names:
    print(n.strip())

Як зчитати та очистити дані одним рядком

Замість того, щоб спочатку зчитувати всі рядки, а потім писати окремий цикл для очищення тексту від \n, можна зробити це відразу під час зчитування: 

with open("names.txt", "r") as file:
    names = [name.strip() for name in file.readlines()]
  
print(names)

Конструкція [name.strip() for name in file.readlines()] — це короткий спосіб записати цикл for. Вона створює новий список [], де до кожного елемента name зі списку, який повертає file.readlines(), автоматично застосовується метод .strip().

Довгий варіант цього коду виглядав би так:

names = []
for name in file.readlines():
    names.append(name.strip())

Теорія 2: Запис у файли

▶

Запис у файли

Читання дає змогу програмі скористатися вже наявними даними, але щоб дані зберігалися після роботи програми, потрібно вміти їх туди записувати. Саме запис у файл перетворює будь-яку програму (щоденник, список справ, список фільмів) із такої, що "забуває" все після закриття, на таку, що справді зберігає прогрес.

Режими запису "w" та "a"

Файл можна відкрити у двох режимах запису:

  • "w" (write) — перезаписує весь файл: якщо у файлі вже щось написано, все видаляється, і у файл записуються нові дані.
  • "a" (append) — дописує новий вміст у кінець файлу, не видаляючи те, що там вже було. 
with open("diary.txt", "w") as file:
    file.write("First entry\n")

with open("diary.txt", "a") as file:
    file.write("Second entry\n")

Після виконання цього коду файл diary.txt міститиме обидва рядки, оскільки другий запис здійснено в режимі "a". Якби другий open() теж використовував "w", перший рядок було б втрачено.

Метод .write() записує рядок у файл. На відміну від print(), він не додає перехід на новий рядок автоматично — про символ \n потрібно подбати самостійно, якщо записуєш кілька рядків.

Запис кількох рядків у циклі

Часто потрібно записати не один рядок, а кілька. Наприклад, зберегти дані, отримані від користувача через цикл: 

with open("notebook.txt", "a") as file:
    while True:
        entry = input("Enter an observation (or 'done' to stop): ")
        if entry == "done":
            break
        file.write(entry + "\n")

Ще один приклад – як записати у файл вміст списку:

names = ["Sam", "Mary", "Nick"]

with open("name.txt", "w") as file:
    for name in names:
        file.write(f"{name}\n")
        
print("names.txt content was updated")

Як видалити елемент зі списку за номером?
Якщо ти виводиш список на екран із нумерацією (1, 2, 3...) і просиш користувача ввести номер елемента для видалення, пам'ятай, що індекси в списках Python починаються з нуля. Тому від введеного номера завжди треба віднімати одиницю: 

idx = int(input("Введіть номер елемента для видалення: "))
del mylist[idx - 1]

Теорія 3: Обробка помилок

▶

Обробка помилок

Досі, якщо програма отримувала несподівані дані (наприклад, замість числа — текст, або назву файлу, якого не існує), вона аварійно завершувала роботу з повідомленням про помилку (traceback). Обробка помилок дозволяє передбачити такі ситуації заздалегідь і відреагувати на них коректно — вивести зрозуміле повідомлення та продовжити роботу програми, а не "зламати" її.

Що таке помилка (traceback)

Коли під час виконання програми трапляється щось, із чим Python не може впоратися (наприклад, спроба перетворити слово на число), програма зупиняється і виводить повідомлення про помилку — traceback. Це повідомлення не є чимось "поганим": воно просто вказує, що саме пішло не так і в якому рядку коду це сталося, щоб допомогти розробнику знайти і виправити проблему.

Конструкція try/except

Щоб "перехопити" помилку і не дати програмі аварійно завершитися, використовують конструкцію try/except: код, який може викликати помилку, розміщують у блоці try, а те, що робити у разі помилки, — у блоці except. 

try:
    number = int(input("Enter a number: "))
except ValueError:
    print("That's not a valid number.")

Конкретні типи винятків

Різні помилки мають різні назви (типи винятків), і кожну з них можна обробляти окремо:

  • ValueError — виникає, коли значення має неправильний тип чи формат (наприклад, спроба перетворити слово "hello" на число).
  • FileNotFoundError — виникає при спробі відкрити файл, якого не існує.
  • ZeroDivisionError — виникає при діленні на нуль.
  • IndexError — виникає, коли відбувається звернення до елемента списку за індексом, якого не існує (наприклад, спроба отримати п'ятий елемент у списку з трьох). 
try:
    with open("case_file.txt", "r") as file:
        lines = file.readlines()
except FileNotFoundError:
    print("No case file found. Starting a new investigation.")
    lines = []

Можна обробити кілька типів помилок в одному блоці try, вказавши кілька блоків except: 

try:
    a = int(input("Enter first number: "))
    b = int(input("Enter second number: "))
    result = a / b
    print(f"Result: {result}")
except ValueError:
    print("Please enter valid numbers.")
except ZeroDivisionError:
    print("You can't divide by zero.")

Приклад обробки IndexError разом із перевіркою на правильність введеного числа: 

colors = ["red", "green", "blue"]

try:
    index = int(input("Enter an index of an element to remove: "))
    del colors[index]
    print("Item removed successfully.")
except ValueError:
    print("Please enter a valid integer.")
except IndexError:
    print("Error: index is out of range.")

Теорія 4: Оптимізація роботи (Функції)

▶

Структура програми

У попередніх частинах ми писали конструкцію with open(...) щоразу, коли треба було прочитати чи змінити файл. Коли програма стає більшою, ми починаємо постійно копіювати той самий код для різних файлів. Це робить код заплутаним і довгим. Значно ефективніший підхід — написати дві універсальні функції (одну для безпечного читання, іншу для запису). Після цього можна повторно використовувати їх для будь-якого файлу.

Читання файлу у функції

Логіку читання зручно об'єднати з перевіркою на помилки. Наша функція load_file(filename) буде приймати назву файлу, безпечно його відкривати і повертати готовий список очищених рядків. Якщо ж файлу немає, вона просто поверне порожній список, щоб програма не аварійно не завершувалась. 

def load_file(filename):
    try:
        with open(filename, "r") as file:
            lines = file.readlines()
        return [line.strip() for line in lines]
    except FileNotFoundError:
        return []
    
names = load_file("names.txt")

Тепер для всього іншого коду не має значення, чи існував файл: виклик load_file() завжди надійно повертає список, з яким можна одразу працювати.

Запис у файл у функції

Так само ми можемо винести в окрему функцію і логіку запису. Функція save_file(filename, data) буде приймати назву файлу та список даних, який треба туди зберегти. Сама функція нічого не повертає (не має return). 

def save_file(filename, data):
    with open(filename, "w") as file:
        for item in data:
            file.write(item + "\n")
          
names = ["Mary", "Eve"]
save_file("names.txt", names)

names.append("Sam")
save_file("names.txt", names)

Виклик save_file("names.txt", names) повністю перезаписує вказаний файл поточним вмістом списку.

load_file() та save_file() разом

Коли у нас є ці дві функції, алгоритм взаємодії з файлами завжди складається з трьох простих кроків:
завантажити список → змінити список у пам'яті → зберегти список у файл.

Ось приклад того, як легко можна додати новий колір і видалити один зі старих: 

# 1. Завантажуємо поточні дані
colors = load_file("colors.txt")
print("Початкові кольори:", colors)

# 2. Змінюємо дані в оперативній пам'яті
colors.append("purple")  # додаємо новий елемент
del colors[0]            # видаляємо перший елемент (індекс 0)

# 3. Зберігаємо оновлений список у файл
save_file("colors.txt", colors)

print("Файл успішно оновлено!")

Частина 1: Створення функцій

  • У новому файлі спробуй написати з пам'яті (або підглядаючи в теорію, але без копіювання) дві функції: load_file(filename) читання даних з файлів та save_file(filename, data) для збереження даних.
  • Проговори вголос, як вони працюють: що робить кожен рядок, навіщо потрібен блок try/except у першій функції і навіщо ми додаємо "\n" у другій.

Частина 2: Застосування функцій

  • За допомогою load_file() зчитай вміст файлу clues.txt у змінну clues.
  • Виведи текст "Adding a new clue:" і запитай користувача про новий доказ ("Enter the name of a new clue: ").
  • Додай цей новий доказ до списку clues.
  • Використай save_file(), щоб зберегти оновлений список назад у файл clues.txt.
  • Виведи повідомлення про успіх: File clues.txt was successfully updated!
